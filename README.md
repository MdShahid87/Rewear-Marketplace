# ReWear — Clothing Exchange & Swap Marketplace

**Swap More. Waste Less. 🌿**

ReWear is a responsive clothing exchange marketplace frontend that allows users to explore pre-loved clothing and discover a more sustainable way to refresh their wardrobes.

The project focuses on creating a clean, user-friendly interface for browsing clothing, viewing listings, and exploring a clothing swap experience.

## 🌱 About the Project

Many people have clothes they no longer wear, while others are looking for new clothing options. ReWear aims to make clothing exchange easier through a dedicated marketplace interface.

This project is currently focused on **frontend development**. Backend APIs, database integration, and production authentication are not yet implemented.

## ✨ Features

- Responsive navigation bar
- Clothing listing and browsing interface
- Clothing item cards and detail page UI
- Login and registration page UI
- Swap request interface
- Chat interface design
- User dashboard UI

- Reusable React components

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Visual Studio Code (recommended)

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd rewear-marketplace
```

Replace the placeholder with your actual GitHub repository URL.

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

http://localhost:5173

### 4. Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎨 Design Direction

ReWear uses a nature-inspired visual identity to communicate sustainability and clothing reuse.

- **Forest Green:** Primary brand color
- **Cream / White:** Clean backgrounds
- **Sage Green:** Supporting accent
- **Typography:** Clear and readable text
- **Layout:** Responsive and reusable UI components
